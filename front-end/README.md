# GameShelf frontend

React en TypeScript met Vite. De startpagina staat in `src/App.tsx`; het React-entrypoint is `src/main.tsx`. Styling komt later.

## Starten

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev`: lokale ontwikkelserver met automatische updates.
- `npm run lint`: code controleren met Oxlint.
- `npm run build`: TypeScript controleren en de webapp bouwen in `dist/`.
- `npm run preview`: de gebouwde webapp lokaal bekijken.

De map `../back-end/` is gereserveerd voor de toekomstige C#-API.
